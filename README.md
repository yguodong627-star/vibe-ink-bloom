# 墨韵 Ink Bloom

宣纸上点按拖动落墨，像真实毛笔一样运笔：可换色、调浓淡、清空、导出 PNG。

## 笔刷特点

- **圆滑连续的笔画**：对鼠标/触控轨迹做低通平滑 + 二次样条插值，按约 1.8px 间距密集落笔，不再是一串圆点。
- **笔宽随速度与压感变化**：慢则粗、墨重；快则细、有飞白；支持手写笔/触控压感。起笔有顿，收笔出尖。
- **鬃毛与飞白**：笔头由数十根鬃毛组成，快速运笔时按噪声在宣纸纹理上断续，产生飞白；墨量随行笔渐少。
- **晕染**：笔画落定后边缘轻微渗透、带宣纸纤维毛边，随后慢慢并入纸面；叠加处墨色加深，浓淡渐变。
- **宣纸纹理**：程序生成的纤维与纸齿，保留原有纸纹风格。
- 单文件、无外部依赖；离屏画布分层渲染，空闲时不重绘，手机触控流畅。
- 小技巧：键盘 `[` / `]` 可缩小/放大笔（触屏靠速度与压感变化笔宽）。
